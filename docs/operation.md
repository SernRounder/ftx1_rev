# Yaesu FTX-1 修复版使用说明

适用于本地生成的 **DISPLAY V01-10 + MAIN V01-13** 联合固件，包含机内 FT8 收发、CW 摩尔斯译码和 SWR 驻波比扫描。固件文件、底包选择、SHA-256 和恢复入口见 [复现指南](reproduce.md)。本版已通过启动、按键及收发仿真回归，实机刷写与射频表现仍待上机确认。

## 1. 启用三个功能

1. 使用复现指南中成对生成的 DISPLAY 与 MAIN，重启后回到普通 VFO 主画面。
2. 短按 **[FUNC]** 进入改版的设置菜单，进入 **DISPLAY SETTING → BUTTON SETUP**。部分参考资料把该分类写作 `DISPLAY SETTINGS`。
3. 选择一个槽位，例如 `PAGE 1-1`。按 **[FUNC]** 或触摸条目进入编辑，转动 **[FUNC]** 或点数值两侧的 **< / >**，找到目标名称，再按 **[FUNC]** 确认。`SWR SCAN`、`FT8` 和 `CW_DEC` 排在候选功能列表末尾。为三个功能各分配一个槽位。
4. 按硬件 **[BACK]** 退回主画面。点底栏固定的 **PAGE** 键切换第 1–4 页，找到刚才分配的三个软键。以后从底栏直接进入。

| 可分配的软键 | 常用的起始状态 | 进入后看到什么 |
| --- | --- | --- |
| `FT8` | 已调到有 FT8 信号的 VFO，通常用 `DATA-U` 或 `USB` | `FT8 DECODE` 双列解码区和 FT8 专用底栏 |
| `CW_DEC` | 普通 VFO 主画面，当前接收机设为 `CW-U` 或 `CW-L` | 原底栏上方出现三行译码条 |
| `SWR SCAN` | 单 VFO 显示、VFO 模式、接收状态、`TUNER OFF` | 驻波曲线区和 `BW / START / STOP / EXIT` 底栏 |

每页有 5 个可配置槽，`PAGE 1-1` 到 `PAGE 4-5` 共 20 个。编号中的第一个数字是页号，第二个数字是该页实际快捷键的位置，从固定的 `PAGE` 键右侧开始数。可把三个功能放到同一页，例如 `PAGE 1-1 = FT8`、`PAGE 1-2 = CW_DEC`、`PAGE 1-3 = SWR SCAN`。分配会占用所选槽原来的快捷键，配置由电台保存。 [Yaesu FTX-1 操作手册，Setting Menu](https://www.yaesu.com/Files/4CB893D7-1018-01AF-FA97E9E9AD48B50C/FTX-1_OM_ENG_EH084M201_2506E-DS.pdf) · [SQ9PD 改版分页与按键说明](https://github.com/sq9pd/Yaesu-FTX-1-mod/blob/ee71225da9db6200a8098547f4f00b6caf438371/README.md)

三个功能一次只显示一个。CW 译码条下方保留原快捷栏，可以直接点 `FT8` 或 `SWR SCAN` 切换。FT8 和 SWR 有各自的底栏，先用各自的 `BACK` 或 `EXIT` 返回主画面，就能选择另一个功能。

## 2. FT8

### 先确认接收

1. 在普通 VFO 主画面选择 `USB` 或 `DATA-U`，调到有 FT8 信号的频率，再点底栏 **FT8**。频率和工作模式仍通过电台原有控制设置。
2. 初次只收听时，打开 **SETUP**，把 **AUTO QSO** 切到 **OFF**，再退回解码区。该开关开机默认是 **ON**，在发射参数已经就绪时，点选合格的 CQ 或发给本台的报文可启动自动应答。
3. 等待约一个完整的 15 秒接收窗和解码时间。信号恰好从半途进入时，可再等一两个时隙。机内解码可独立运行。

### 解码区和底栏

| 界面项目 | 怎么用 |
| --- | --- |
| `00/30`、`15/45` | 两列分别记录每分钟从第 00／30 秒和第 15／45 秒开始的时隙。列标题的 `TX` 标明本台所选发射时隙。 |
| `RX #`、`AVG D` | 前者是该列的解码批次号，后者是这一批报文相对于当前时隙基准的平均时间残差。看到 `--` 表示暂时没有该批次的有效平均值。 |
| `km`、`dB`、`Hz` | 分别是估算距离、信噪比和收到报文的音频频偏。有双方格网信息时才能估算距离。 |
| 报文行 | 点有可识别发信方的报文，可选中对方呼号并带入测得的信号报告。启用 `AUTO QSO` 时，合格报文可同时启动该台的自动通联。 |
| `RARE / dB / km` | 点击循环切换排序。含本台呼号的报文优先，有 SD 履历时已通联台靠后。`RARE` 优先本批次较少见的呼号前缀，`dB` 按信号强度，`km` 按距离。 |
| `PAGE n/m` | 点击循环翻页。每一页每列最多显示 3 条报文。 |
| `TX NEXT`、`STOP` | `TX NEXT` 把预览的报文排入下一个合适的所选时隙。`STOP` 取消等待中的发射、正在发送的报文或正在运行的自动通联，并让界面留在 FT8。 |
| `SETUP`、`BACK` | `SETUP` 打开设置。屏幕或硬件 `BACK` 依次退回上一级，键盘 → 设置 → 解码区 → 主画面。退出 FT8 会结束当前自动通联或发射请求。 |

### 发射前在 SETUP 里核对

| 设置 | 含义和操作 |
| --- | --- |
| `MY CALL` | 本台呼号。有可用的原厂 `MY CALL` 时会预填。请核对，也可点此编辑。 |
| `DX CALL` | 对方呼号，适用于定向报文。可由解码行选入，也可手填。手改后原先选中行的信号报告需要重新取得。 |
| `GRID` | 本台 Maidenhead 格网，可输 4 位或 6 位。有效 GPS 位置优先，失去有效定位时回退到手填格网。标准 FT8 格网报文使用前 4 位。 |
| `TX Hz` | 发射音频频偏，范围 200–2800 Hz，默认 1000 Hz。发射请求会锁定当次使用的数值。 |
| `TIME OFFSET` | 本地 FT8 时隙修正，单位秒，范围 −7.5 到 +7.5。首次发射前要打开此项并确认一个值，即使输入的是 `0`。正值推迟 FT8 时隙，负值提前。此项只修正 FT8，可结合多批信号的 `AVG D` 判断残差。 |
| `TX SLOT` | 轻触切换 `00/30` 与 `15/45`，回答对方时选择另一列的时隙。排队、发射或自动通联期间先点 `STOP` 再改。该选项与报文模板上的 `TX1…TX6` 各自独立。 |
| `DATE/TIME` 或 `GPS TIME` | 时隙依赖电台时钟。`DATE/TIME` 可按 `YYYYMMDDHHMMSS` 修改电台的本地日期与时间。启用 GPS 自动校时时显示 `GPS TIME`，由系统管理。 |
| `SET … W` | MAIN 回报的发射功率设定。`SET --` 表示暂缺功率回报。调整功率用电台原有 `RF POWER`。 |

点键盘的确认键提交，点 **BACK** 取消当次编辑。重启后再次检查 `TIME OFFSET` 和发射时隙。确认工作模式为 `USB` 或 `DATA-U`、实际频率和功率适合当次操作，再启用发射。

### 手动、自动与全自动通联

- **手动发送**。将 `AUTO QSO` 设为 `OFF`。选择对方或填写所需字段。在 `SETUP` 右下角轻触报文选择区轮换 `TX1` 格网、`TX2` 信号报告、`TX3` 确认报告、`TX4` RRR、`TX5` 73、`TX6` CQ。点 `FREE` 可编辑自由文本，最多 13 个字符。核对预览和发射列，再点 `TX NEXT`。随后可见 `ARMED` 倒计时、`TX`，发送完毕回到 `RX`。
- **AUTO QSO**。设为 `ON` 并选好应答时隙，返回解码区，点一条新收到的 CQ，或一条发给本台且处于适合应答阶段的报文。固件会按阶段发送并等待同一对方的有效回复。`WAIT REPLY` 表示等待对方。完成、重试用尽或超时后结束本轮。`QSO RETRIES` 设置每个待应答步骤的额外重试次数，范围 0–99，默认 5。可随时按 `STOP` 结束当前通联。
- **FULL AUTO**。先检查本台呼号、格网、时间、发射时隙和音频频偏，并插入电台可读写的 SD 卡。在 `SETUP` 里轻触值为 `START` 的 `FULL AUTO` 一行。固件在所选时隙发 CQ，将发给本台的合格应答加入队列，并核对 SD 履历后逐台处理。返回解码区可查看 `QSO`、`Q`、`CQ`，分别表示已完成数、待处理数和剩余 CQ 轮次。`CQ ROUNDS` 为 1–99，默认 3，输入 `-1` 则持续运行直至取消。使用 `END AUTO`、`STOP` 或退出 FT8 结束。SD 履历读取失败会中止全自动接续。

完成符合结束条件的标准通联后，固件可在 SD 卡的 `FTX-1/FT8LOG.ADI` 追加 ADIF 记录。`SETUP` 右侧的 `RECENT QSOs (UTC)` 显示最近 6 条记录和 UTC 时间，历史行用于查看。

| 看到的状态 | 下一步 |
| --- | --- |
| `SET TIME OFFSET` | 到 `SETUP` 确认时间修正值。时钟准确时也可以明确提交 `0`。 |
| `NO SLOT` | 检查电台时钟、`TIME OFFSET` 和所选时隙后再排队。 |
| `TX OFFLINE` 或 `TX FAULT` | 点 `STOP`，确认回到接收，并核对配套 MAIN、`USB / DATA-U` 模式及是否有其他 PTT、录音或播放占用。 |
| 解码区暂无报文 | 等满一个接收窗，核对当前频率、边带和音频通带。调谐完毕后重新观察。 |

## 3. CW_DEC

1. 回到普通 VFO 主画面，把要听的接收机设为 **CW-U** 或 **CW-L**，调到清晰的摩尔斯信号。
2. 点底栏 **CW_DEC**。译码条出现在原底栏上方，仍可转动 VFO 调谐或使用原有软键。解码器以当前接收 VFO 的原厂 **CW PITCH** 为目标音调，可用电台的 `ZIN` 或 `CW SPOT` 辅助对准。
3. 等译码器判断音调和点划速度。最近三行文本滚动保留。换频、改边带、改音调或本机发射时，当前字符会中断，回到合适的接收条件后可重新捕获。
4. 点译码条右侧 **CLOSE**、按硬件 **BACK**，或再点底栏 **CW_DEC**，均可关闭译码条。

| 字样 | 含义和操作 |
| --- | --- |
| `WAIT 600 R…` | 已进入可用接收状态，正在寻找稳定的点划。示例中的 `600` 是目标音调 Hz，`R` 后是捕获帧计数。 |
| `20WPM 600 R…` | 示例表示估计接收码速为每分钟 20 词，按 600 Hz 的目标音调接收。 |
| `CW-U/L` | 当前没有有效的 CW 接收源。检查是否正在发射、当前 VFO 是否为 CW、是否仍停在列表或菜单中。返回普通 VFO 主画面再试。 |
| `CW OFFLINE` | 译码工作任务尚未就绪。若刚退出 FT8，先等收发结束，再观察或重新打开译码条。 |
| `F… D… P… L…` | 尚无译文时可能出现的诊断，依次为帧字数、声道识别结果、捕获峰值、目标音调能量。若 `R` 在增但长期只有 `WAIT`，先听信号是否清晰并重新对准 `CW PITCH`。 |

原厂 CW 调谐操作见 [Yaesu FTX-1 操作手册，CW Operation](https://www.yaesu.com/Files/4CB893D7-1018-01AF-FA97E9E9AD48B50C/FTX-1_OM_ENG_EH084M201_2506E-DS.pdf)。

## 4. SWR SCAN

### 准备与开始

1. 选定要测量的天线端口，接好天线或额定功率合适的假负载。将电台置于 **单 VFO 显示**、**VFO 模式**和 **RX**，关闭 **TUNER**。开始前关闭 `SPLIT`、`RIT`、`XIT` 和其他发射频率偏移，使收发使用同一 VFO。
2. 点底栏 **SWR SCAN** 打开窗口。在等待画面中转动主 VFO 设置中心频率，点 **BW** 循环选扫宽。改变中心频率或扫宽会清掉旧曲线。
3. 确认整个范围的起点和终点都在可发射范围内，再点 **START**。从低频到高频扫一轮，总计 101 个点。**打开窗口只进入等待，START 才发射。**扫描期间使用 AM，设定功率为 Field 机头 1 W、使用 SPA-1 时 5 W。扫频过程中观察 TX 指示，并保持天线接线、VFO 和扫宽设置稳定。 [SQ9PD 扫描说明与限制](https://github.com/sq9pd/Yaesu-FTX-1-mod/blob/ee71225da9db6200a8098547f4f00b6caf438371/README.md#3-swr-scan--instructions-and-limits)

| `BW` 全宽 | 相对中心频率 | 点间步进 |
| --- | --- | --- |
| 50 kHz，入窗默认 | −25 至 +25 kHz | 500 Hz |
| 100 kHz | −50 至 +50 kHz | 1 kHz |
| 500 kHz | −250 至 +250 kHz | 5 kHz |
| 1 MHz | −500 至 +500 kHz | 10 kHz |

### 看图、停止与退出

- **看图**。横轴是频率，纵轴是 SWR，`1` 附近代表更好的匹配。曲线最低处可作为判断天线在哪段匹配较好的参考，测量依据是机内原厂驻波采样。用同一中心频率和扫宽再按 `START` 时，旧曲线会随着扫描游标逐点更新。
- **STOP**。中断扫频并保留当前图形。正常完成或停止后，电台确认回到 RX，再恢复中心频率、工作模式和原发射功率。
- **EXIT 或硬件 BACK**。空闲时关闭窗口并恢复主画面软键。测量中操作会先请求停止扫频，确认回到 RX 后关窗。退出后若要使用 FT8 或 CW_DEC，从主画面重新选择。
- **异常处理**。先点 `STOP` 并观察 TX 指示。若停止后仍持续发射，关闭电台。部分操作条件在扫描窗口内被锁定，改波段、开设置或启动其他功能前先退出。 [SQ9PD 扫描控制与保护说明](https://github.com/sq9pd/Yaesu-FTX-1-mod/blob/ee71225da9db6200a8098547f4f00b6caf438371/README.md#known-limitations-and-safeguards)

| 屏幕错误 | 含义和处理 |
| --- | --- |
| `ERR2` | 扫频条件变化或发射请求冲突。确认已回 RX，检查 PTT、其他扫描与调谐操作。 |
| `ERR3`、`ERRP` | 功率或 SWR 读数无效，或新测量未及时到达。核对天线端口、接线和功放状态。 |
| `ERR6` | 扫描范围或启动条件不符合要求。核对上下边界、VFO、TUNER、收发偏移和功放条件。跨波段或遇到 SPA-1 滤波器切换时，可在合适的子范围分别测量。 |
| `ERRH`、`ERRA` | 显示端未就绪或测量点的应答超时。退出窗口，确认 MAIN 与 DISPLAY 是本目录配套镜像，再检查是否可重现。 |
| `ERRS`、`ERRX` | 扫描会话超时，或恢复 RX 和设置超时。先确认发射已经停止，记录完整错误码，再检查条件。 |
