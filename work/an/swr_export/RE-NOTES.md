# 0x20 状态帧 / TX 遥测 RE 结论(2026-11-12)

为 FT8 页功率/SWR 显示与 SWR 停发做的定点反编译(main-map.bin / display.bin,ghproj)。

## 1. 0x20 帧组装链(MAIN)

```
FFEE3FD6  发送入口:FFEE4003(组装) → FFE459C(校验) → FFE44E8(发送 0x13c)
FFEE4003  清 0x13b + 帧头 [0]=0x20
FFED7A49  主体字段组装(逐偏移,见下表)
```

我们的 `ft8_main_status_hook`(build_ft8_main.py 挂 FFEE3FD6)在组装后、发送前运行。

## 2. TX 遥测(SWR)结论:不在 0x20 帧

- MAIN 把 TX 配置经 `FUN_ffea68ba(0, cmd, value<<2)` 推 IFDSP 命令槽(cmd 1-10),当前值缓存于 0x82ae20-0x82ae30。FFF32068 是**配置推流**(波段滤波/表盘校准,输入是频率与静态波段表),**不是 SWR 测量**。
- ATU 族:DAT_00823379(ATU 在位)、0x8013bb(ATU 状态机 1/2/3)、0x8013ce;FFF38286/38210/3824B 驱动。
- SWR 原始测量(正向/反射)在 IFDSP(MIMXRT685 HiFi4)共享 RAM / DSP blob 深处,静态 RE 到此为止。**需要实机实验**(频谱仪实验同批)。

## 3. 工程方案(2026-11-12 更新)

- PO 显示:已交付 rx5(0x20+32/33 真实数据)。
- SWR:曾按 packet[29]=SWR×10 扩展通道实现过显示与 >2.0 停发全链(VM 注入验证通过),因 MAIN 侧实测数据源缺失(占位写 0,屏幕只显 "--")构成"假壳子",**已按用户决定整体移除**(代码、协议常量、故障码、测试用例全部删除)。将来实机实验在 IFDSP 共享 RAM 定位到正向/反射数据源后,基于本文件的帧布局(偏移 29 为原厂保留零字节可用)重新整体引入。
- 0x20 帧布局表(§1)仍然有效,是将来接入任何 TX 遥测扩展的依据。
